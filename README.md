## KeyboardPSShortcuts

Small Windows scripts for configuring appearance and display functionality.

### Appearance

The `Appearance/` scripts apply Windows appearance settings, such as font substitutions. Run the selected script once when you want to apply the setting.

### Functionality

The `Functionality/` scripts provide display-setting actions. They can be run manually as needed or assigned to keyboard shortcuts for quick access.

### Usage

Run a script directly, or create a shortcut to it and assign a keyboard shortcut in the shortcut's properties. Some scripts modify system-wide Windows settings and may require administrator privileges.
